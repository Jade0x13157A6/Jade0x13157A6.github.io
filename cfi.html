Forward-edge CFI in an out-of-order RISC-V core.

Exploring how landing-pad-based control-flow integrity can be integrated into the execution and retirement behavior of the Sargantana processor.

SystemVerilogRISC-V ZicfilpMicroarchitectureRTL Verification

Context

The RISC-V Zicfilp extension provides forward-edge control-flow integrity by requiring valid landing pads after certain indirect control transfers. Enforcing this mechanism in an out-of-order processor raises questions about speculative state, instruction ordering, exceptions, and recovery.

This work takes place in a RISC-V Mentorship project mentored by researchers at Barcelona Supercomputing Center and Inria (SUSHI team), using the Sargantana out-of-order processor as the implementation context.

Architecture

The design introduces a dedicated Landing Pad Unit (LPU) alongside the branch-resolution logic in the execution stage. The LPU tracks whether a landing pad is expected and validates eligible control-flow targets, including label checks when required.

Key implementation concerns

  • Instruction classification: distinguishing eligible indirect transfers and landing-pad instructions using execution-stage instruction information.
  • Label verification: comparing a landing-pad label against the architecturally relevant expected value.
  • Precise exceptions: propagating software-check faults through the out-of-order pipeline so they can be handled at commit.
  • Speculation and recovery: integrating the LPU's state with existing pipeline flush behavior.

Verification approach

Testing covers landing-pad detection, matching and mismatching labels, dual-instruction situations, exception ordering, speculative flush behavior, and core-level instruction execution. The work includes focused RTL testbenches and instruction-level regression tests.

Public code note. The full mentorship integration is distinct from the public standalone SystemVerilog landing-pad FSM coding exercise. This page intentionally does not present that exercise as the full Sargantana implementation.
