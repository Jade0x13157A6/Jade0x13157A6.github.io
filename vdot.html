Case study · XiangShan · 2026

INT8 vector acceleration with structured sparsity.

Implementing dense and 2:4 sparse vector dot-product operations in XiangShan Kunminghu V2, from hardware design to software validation and pre-layout synthesis.

Chisel / RTLINT8NEMU DifftestYosys / STA

Objective

The goal is to accelerate quantized computation using custom INT8 vector dot-product instructions. The implementation extends the VIAluFix integer vector execution unit and explores both dense arithmetic and 2:4 structured sparsity.

Hardware approach

Dense VDOT processes eight pairs of signed INT8 operands. The sparse variant uses a selection mechanism to choose active operands while reusing shared multipliers and a carry-save adder reduction network. The design includes instruction decoding, reference behavior in NEMU, and integration into the existing vector pipeline.

Functional verification includes XiangShan–NEMU differential testing. Reported area comparisons are based on the mapped VIAluFix module, not a full-chip post-layout result. The application-level tests classify 31 of 32 samples correctly against the dataset labels.
